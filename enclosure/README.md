# Enclosure — 3D 打印外壳（独立项目）

> 面向 Agentic Keyboard (Tuya T5AI-Core) 的 3D 打印外壳设计。
> 本目录是**独立子项目**，有自己的建模源、导出件与打印参数，
> 与固件 / 上位机解耦，可单独迭代与分享。

## 定位

外壳设计与固件/上位机的开发节奏不同（依赖实物尺寸、打印验证、装配试配），
因此从 `hardware/` 中独立出来，放在仓库根目录单独维护。

## 需要容纳的部件

- T5AI-Core 开发板（尺寸参照 `../components/T5AI-Core/T5AI-Core_V101-3D.step`）
- 2.8" LCD（CL28CK230-18A，320×240）开窗
- 5× 茶轴机械键（CPG151101D06）键位
- WS-1002 5 向摇杆开窗
- 板载麦克风开孔 / 扬声器出声孔
- USB / 串口线缆出口

## 目录约定

```text
enclosure/
├── src/        # 参数化建模源（.scad / .FCStd / .step 等）
├── export/     # 可打印导出件（.stl / .3mf）
├── docs/       # 装配说明、打印参数（层高/填充/支撑）、试配记录
└── README.md   # 本文件
```

## 打印与装配

- 打印参数（层高、填充率、支撑、材料）记录在 `docs/`。
- 装配顺序与紧固方式（螺柱/卡扣/热熔螺母）随设计确定后补充。

## 版本管理

- 建模源与最终导出件（`.stl` / `.3mf` / `.step`）**纳入**版本管理。
- 编辑器备份、切片中间产物（`.gcode`、`*.FCStd1`、`*.blend1` 等）由根
  `.gitignore` 忽略。
